[Terra Draw](https://terradraw.io/) provides a unified drawing API for most web mapping libraries — MapLibre GL JS, Mapbox GL JS, Leaflet, OpenLayers, Google Maps and ArcGIS — via adapters. I contribute to Terra Draw itself, and help bring it to more users through:

- **[maplibre-gl-terradraw](https://github.com/watergis/maplibre-gl-terradraw):** a MapLibre plugin I author and maintain, which adds Terra Draw drawing and measuring controls with a single line of code
- **[Terra Draw Workshops](https://workshops.terradraw.water-gis.com/):** hands-on tutorials and workshop materials used at FOSS4G 2025 Auckland and FOSS4G 2026 Hiroshima

**Tech stack:** TypeScript, Terra Draw, MapLibre GL JS
