I started to translate iOS and Android mobile mapping application - [Input](https://inputapp.io) from English to Japanese since January 2021.

In Japan, there are a lot of users who are using iPhone and iPad, however there had been no Japanese mobile solution for QGIS on iOS for a long time. I finally translated Input app to Japanese language for QGIS community in Japan. Now Japanese users have multiple choices either QField or Input for mobile.
