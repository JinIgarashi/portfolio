**Event:** [FOSS4G 2025 Auckland](https://2025.foss4g.org), Auckland, New Zealand

[Terra Draw](https://github.com/JamesLMilner/terra-draw) is a drawing library for cross-platform mapping libraries such as MapLibre, Leaflet, OpenLayers, Mapbox, Google Maps and ArcGIS. It provides a unified API, so developers can build drawing features with the same code across different web mapping libraries.

This 3-hour workshop consisted of two parts:

1. **Introduction:** a presentation on what Terra Draw is and what it can do for map applications.
2. **Hands-on:** coding exercises integrating Terra Draw with MapLibre GL JS, including
   - installation and setup of Terra Draw
   - advanced functionalities such as layer styling and events
   - the [maplibre-gl-terradraw](https://github.com/watergis/maplibre-gl-terradraw) plugin to add a pre-configured drawing control in one line

The workshop also showed how Terra Draw can be used with other mapping libraries, demonstrating its adaptability across platforms. Participants brought laptops with Node.js v22 LTS and VSCode.
