**Event:** [FOSS4G 2026 Hiroshima](https://2026.foss4g.org), Hiroshima, Japan

[Terra Draw](https://github.com/JamesLMilner/terra-draw) is a cross-platform drawing library for MapLibre, Leaflet, OpenLayers, Mapbox, Google Maps and ArcGIS, which enables developers to add drawing capabilities to web map applications.

This beginner-level workshop provided both an introduction and practical experience:

1. **Introduction:** Terra Draw's capabilities and its benefits for map-based applications.
2. **Hands-on:** coding exercises using MapLibre GL JS as the main example, covering
   - installation and setup
   - advanced features such as styling, events and data integration
   - the [maplibre-gl-terradraw](https://github.com/watergis/maplibre-gl-terradraw) plugin

Participants used their laptops with Node.js LTS and VSCode, or GitHub Codespaces. Basic JavaScript knowledge was helpful but not required.
