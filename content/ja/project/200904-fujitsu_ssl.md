**期間:** 2009年4月 〜 2017年3月（2014年4月〜2016年9月はケニアでの活動のため休職）

**所属:** 株式会社富士通ソーシアルサイエンスラボラトリ

ソフトウェアエンジニアとしてキャリアをスタートし、様々な業務システムの設計・開発に携わりました。その多くがGIS関連のシステムであり、GISエンジニアとしてのキャリアの基礎となりました。

## 主なシステム

| システム | 使用技術 |
|---|---|
| 自動運転車向け高精度（HD）地図の開発 | ArcGIS Server, Python, Django REST framework |
| シンガポールにおける船舶の動きをマッピング・シミュレーションするシステム | Leaflet |
| 法務省の不動産登記システム向けWebGIS | MapServer, OpenLayers, Oracle |
| ヘルスケア管理のためのAndroidアプリケーション | Java |
| エリアマーケティングシステム | MapInfo |
| ダイクストラ法による経路探索を用いた物流・配送管理システム | VB.NET, SQL Server, MS Access |

## スキル

VB.NET, Java, Python, OpenLayers, Leaflet, MapServer, ArcGIS Server, SQL Server, MS Access, Oracle
