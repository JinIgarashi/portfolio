GeoHub は UNDP の地理空間データ・サービスを集約したプラットフォームです。GIS の専門知識がなくても、データの検索・可視化・ダウンロード、独自データのアップロード、ラスター解析、地図の作成・共有ができます。フルスタック GIS 開発者として、データアップロードパイプライン、認証、権限管理、地図スタイリング UI など主要機能の多くを開発しました。

**技術スタック:** SvelteKit, MapLibre GL JS, PostgreSQL/PostGIS, titiler, pg_tileserv, STAC, Azure
