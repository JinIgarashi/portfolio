[Terra Draw](https://terradraw.io/) は、アダプターを介して MapLibre GL JS、Mapbox GL JS、Leaflet、OpenLayers、Google Maps、ArcGIS など主要な Web 地図ライブラリに統一的な作図 API を提供するライブラリです。Terra Draw 本体の開発に貢献するとともに、以下を通じて普及に取り組んでいます。

- **[maplibre-gl-terradraw](https://github.com/watergis/maplibre-gl-terradraw):** 私が開発・メンテナンスしている MapLibre 用プラグイン。1行のコードで Terra Draw の作図・計測コントロールを追加できます
- **[Terra Draw ワークショップ](https://workshops.terradraw.water-gis.com/):** FOSS4G 2025 オークランド・FOSS4G 2026 広島で使用したハンズオン教材

**技術スタック:** TypeScript, Terra Draw, MapLibre GL JS
